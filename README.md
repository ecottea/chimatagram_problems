
# ✨ チマタグラムクイズ

文字を並べ替えて指定されたジャンルの言葉を当てる、シンプルなブラウザ向けクイズアプリです。
普通のアナグラムと違い、**「余計なダミー文字が1文字」** 混ざっています。

## 🎮 遊び方
1. 画面上部のプルダウンから、挑戦したい**ジャンル**を選択します。
2. 画面に表示される「問題（文字の羅列）」を見て、元の言葉を推理します。
   * ※必ず**1文字だけ**無関係な文字が混ざっています。
3. わかったら（または降参したら）「💡 答えを見る」ボタンを押します。
4. 正解と、ダミーとして混ざっていた「余計な1文字」が表示されます。
5. 「次の問題へ ➔」や「🎲 ランダム」ボタンでどんどん問題を解いていきましょう！
